# Teste 01 — Resumo exploratório

## Objetivo

Realizar uma primeira exploração das fontes do caderno sobre investimentos para iniciantes, identificando os principais conceitos apresentados.

---

## Prompt utilizado

```text
Faça um resumo dos principais conceitos apresentados nas fontes deste caderno sobre investimentos para iniciantes.
```

---

## Estratégia utilizada

Foi utilizado um prompt aberto e exploratório, sem delimitação dos conceitos, estrutura específica ou nível de conhecimento do estudante.

O objetivo desta primeira tentativa foi observar como o NotebookLM organizaria espontaneamente as informações disponíveis nas fontes.

---

## Resultado da resposta

A resposta apresentou uma visão ampla dos principais assuntos relacionados a investimentos.

Entre os temas abordados estavam:

- retorno;
- risco;
- liquidez;
- renda fixa;
- renda variável;
- estrutura do mercado de ações;
- IPO;
- follow-on;
- Tag Along;
- análise fundamentalista;
- análise técnica;
- vieses comportamentais;
- educação financeira.

A resposta conseguiu reunir diferentes informações presentes nas fontes, porém apresentou um escopo maior do que o necessário para o objetivo de estudar os conceitos fundamentais de investimentos para iniciantes.

---

## Análise crítica

A primeira resposta foi útil como exploração inicial do conteúdo, mas não apresentou uma estrutura específica para aprendizagem dos conceitos escolhidos.

Os principais problemas identificados foram:

- escopo muito amplo;
- ausência de definição do nível de conhecimento do estudante;
- ausência de conceitos previamente delimitados;
- falta de uma estrutura obrigatória para cada conceito;
- inclusão de assuntos que não eram diretamente necessários para o objetivo inicial.

---

## Principal aprendizado

A primeira tentativa mostrou que um prompt muito aberto pode gerar uma resposta extensa e abrangente, mas isso não significa necessariamente que ela esteja adequada ao objetivo de aprendizagem.

Para melhorar o resultado, o próximo prompt deveria:

1. definir claramente o público-alvo;
2. delimitar os conceitos a serem estudados;
3. estabelecer uma estrutura para cada conceito;
4. restringir o conteúdo ao objetivo definido;
5. solicitar referências das fontes utilizadas.

---

## Cicatriz do Teste 01

> **Prompt muito amplo gera uma resposta abrangente, mas não necessariamente uma resposta adequada ao objetivo de estudo.**

Essa limitação levou à criação do Teste 02, no qual os conceitos e a estrutura da resposta foram definidos previamente.

---

## Referências

As informações foram geradas pelo NotebookLM utilizando exclusivamente as fontes adicionadas ao caderno do projeto.

As fontes utilizadas no caderno estão documentadas no README principal deste repositório.
